Inspired by GitHub Copilot Brushes, Spaghettify asks what would happen if an AI coding assistant optimized for making software worse.

It can introduce bugs, obscure code, document everything with emoji, add random whitespace, and perform other acts of deliberate degradation. At launch it reached the top position on Hacker News and accumulated thousands of downloads.
