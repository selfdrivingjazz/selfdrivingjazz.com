Cursed UI is an open-source React component library that treats familiar interface patterns as material for small, unexpected interactions. Components are presented with polished documentation, a shadcn-compatible registry, and copyable standalone source.

The first release is an OTP input built as a self-contained controlled React component with accessible keyboard behavior. The project includes a component index, installation guides, and an interactive demo.
