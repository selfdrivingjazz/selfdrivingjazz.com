Cuelight is an open-source alternative to BrightSign: a control plane and player runtime for sending media to physical screens. Cheap Raspberry Pi-class players pair with a controller, which publishes immutable signed releases, assigns them to screens, streams or caches content-addressed media, supervises playback and reports what each screen is actually showing.

Operators run a wall of screens from one place: media files and live web pages, playlists, profiles that switch every screen at once, screenshots of what's on air, and a phone remote. Desktop apps and ordinary browsers, smart TVs included, can join as screens too.

It's in development: early foundation work, with no stable release or API guarantee yet.
